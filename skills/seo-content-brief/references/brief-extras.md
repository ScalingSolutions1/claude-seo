# Brief Extras: Setup, Evidence, Measurement, Answer-Led Article

Optional sections to add to the brief Output Format, plus an article blueprint.

## Extra brief sections

### Brief Setup
Content goal (traffic / leads / education / awareness) · Audience · Tone
(professional / conversational / technical) · Content type

### Data Sources
Each source used, key numbers, and the date pulled.

### Index Status (improve mode)
URL Inspection coverage state and date. If not indexed, remediation comes
before the rewrite (`seo-google/references/indexing-remediation.md`).

### SERP Model
Top 3 page types; the single page to beat and exactly why it wins (depth,
links, format, freshness).

### Title Options
3 options, primary keyword near the front, 50-60 characters.

### Answer-First Paragraph (draft)
40-60 words that answer the main question directly and name the entity.

### Unique Data Points
Numbered facts only this site can provide: own measurements, specs, test
results, prices, delivery times per region, photos of the real thing, case
outcomes. Aim for 10-15+ on cornerstone pages (a working heuristic, not a
Google threshold).

### Sources to Cite
2-5 specific authoritative sources (primary data, standards bodies,
regulators, peer-reviewed papers, official documentation) and the claim each
supports. No competitor blogs as sources.

### Visual Plan
Hero image plus supporting visuals (screenshots, diagrams, charts, comparison
tables), each with its purpose and an alt-text note.

### Off-site Actions
Lists, directories, communities and video to pursue for this topic
(`seo-geo/references/offsite-entity-building.md`).

### Measurement
Search Console query and page to watch, baseline position and clicks, review
date (4-8 weeks).

## Answer-led article (informational and evaluation queries)

| Section | Purpose | Format |
|---|---|---|
| Title | Match a real question or comparison | Question or "[A] vs [B]" form, taken from the question bank or prompt panel |
| Short answer | Snippet and AI-answer target | 60-110 words; the core answer in the first 40-60 |
| Question H2s | Cover sub-questions | Each H2 is a real user question; the first paragraph under it answers it on its own, then detail follows; count follows the topic (often 6-12) |
| Data table | Extractable comparison | One table where the topic allows (criteria, options, conditions, scenarios) |
| Q&A block | Long-tail questions | 5-7 questions, 40-70-word answers, plain HTML |
| Sources | Verifiability | Primary sources with links (DOI where available) |
| Related reading | Internal links | 3-6 links: guides, product or category pages, sister pillars, and the same article in other languages |

Schema: Article / BlogPosting with author Person and publisher Organization.
Every section must add something new; cut any H2 that only repeats the short answer.
